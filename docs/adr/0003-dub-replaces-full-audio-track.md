# Dub output replaces the full audio track; background audio is not preserved

Status: accepted (2026-11-14)

The `dub` stage builds `output_dub.mp4` by replacing the source audio track wholesale: the new track is a silence bed of the source duration with each synthesized TTS segment placed at its original timeline position (speech slots from `segments.json` word timestamps), and every non-speech gap stays silent. Mixing TTS over a ducked original or preserving background-only audio outside speech slots was considered and declined. Rationale: the repo has no usable vocal-separation path (the demucs/TTS tooling was explicitly retired, `docs/agents/tool-audit.md`), so background preservation would reintroduce a retired dependency or tolerate uncontrolled residue; full replacement is the only variant whose timeline is fully deterministic — slot fitting (speed cap 1.25×, overflow into adjacent silence, cumulative overflow ≤ 2%) can be gated mechanically, which is what the no-drift acceptance for 1h runs measures. Subtitle burning stays out of `dub` scope: `output.mp4` (burn) and `output_dub.mp4` are independent artifacts. Reopening condition: a requirement to keep background music/score would need a new vocal-separation spec, not a quiet amendment of this ADR.
