# TTS engine is F5-TTS with a named fixed-voice library; cloning is interface-only in v1

Status: accepted (2026-11-14)

The `tts` stage runs F5-TTS on the official `SWivid/F5-TTS_Emilia-ZH-EN` weights (ModelScope, CC-BY-NC-4.0; the non-commercial restriction is accepted for this personal context). Voices come from a named library of fixed reference clips (`zh-female-01`, `zh-male-01`, `en-female-01`, `en-male-01` minimum) stored under a gitignored assets dir (`_model_cache/tts_voices/`) so no NC-licensed audio enters the public repo; voice cloning is the same mechanism with a different reference clip and stays config-interface-only in v1. The library replicates the named-catalog selection experience the maintainer knew from Microsoft Edge TTS; Edge TTS itself is a cloud service and is excluded by the zero-cloud constraint.

Selection criteria were simplicity, speed, and quality stability. F5-TTS wins all three: `pip install f5-tts` is the lightest install; the non-autoregressive (flow-matching) architecture is mechanically immune to the repetition and timbre-drift accumulation that autoregressive TTS shows on long runs — the exact failure mode the 1h no-drift gate targets; stock PyTorch RTF 0.147 meets the TTS E2E RTFx ≤ 0.5 acceptance gate without any compiled-accelerator work (TRT/vLLM are explicitly out of scope, `docs/agents/execution-chain.md` acceleration policy). Its known weakness, chunk-boundary seams, is dissolved by the per-segment synthesis design (each segment starts from the reference clip; no long intra-call concatenation), and slot fitting uses ffmpeg `atempo` because F5 has no native speed parameter.

Rejected alternatives, recorded to stop re-litigation: Qwen3-TTS-12Hz-1.7B-Base (strongest long-form benchmark and Apache-2.0, but released 2026-01 with few production cases and native RTF 2.0 unless FlashAttention2 installs cleanly); IndexTTS-2.5 (best Chinese long-form reputation, RTF 0.21, but heaviest install chain and a custom license); CosyVoice2/Fun-CosyVoice3-0.5B-2512 (native RTF ~0.70 misses the 0.5 gate; documented >15 s repetition issue #1420 — the weights already in `_model_cache/cosyvoice3/` remain an unused leftover); GPT-SoVITS (fastest at RTF 0.014 but documented VRAM accumulation OOM on long runs, issue #1519 — a direct conflict with 1 h continuous operation). Reopening conditions: the acceptance quality gate failing, voice cloning becoming a first-class requirement, or commercial use of outputs (CC-BY-NC would need re-examination).
